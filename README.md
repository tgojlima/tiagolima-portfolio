O projeto está publicado e pode ser acessado em: **[tiagolima-portfolio.netlify.app](https://tiagolima-portfolio.netlify.app/)**

## 📖 Sobre o Projeto
Este é o meu portfólio profissional pessoal. Desenvolvido com HTML5 semântico, CSS3 moderno (arquitetura organizada, Custom Properties, BEM/ITCSS e responsividade total) e JavaScript puro para otimização de performance.

O objetivo deste projeto não é apenas ser uma vitrine dos meus projetos técnicos, mas demonstrar domínio sobre metodologias ágeis, boas práticas de UI/UX, SEO (Meta Tags Open Graph e Twitter Cards), Acessibilidade e organização de código.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica, validação e acessibilidade.
- **CSS3:** Estilização componentizada, media queries para responsividade e design system com variáveis globais.
- **JavaScript (ES6+):** Manipulação de DOM segura e modularizada.
- **Font Awesome 6.4.0:** Iconografia.
- **Netlify:** Hospedagem estática com CI/CD.

## 📁 Estrutura de Diretórios
```text
📦 portfolio
 ┣ 📂 assets
 ┃ ┣ 📂 videos          # Demonstrações em vídeo dos projetos (mp4)
 ┃ ┣ 📜 ...             # Imagens otimizadas (.jpeg, .png, .jpg)
 ┃ ┗ 📜 curriculo-tiago-2026.pdf
 ┣ 📜 index.html        # Página principal (Home, Sobre, Habilidades, Contato)
 ┣ 📜 projetos.html     # Página detalhada com mídia/screencasts de cases
 ┣ 📜 certificados.html # Galeria de diplomas e conquistas
 ┣ 📜 style.css         # Estilização global e componentes
 ┣ 📜 script.js         # Lógica da aplicação e interatividade
 ┣ 📜 robots.txt        # Configurações de indexação para bots
 ┣ 📜 sitemap.xml       # Mapa do site para SEO
 ┣ 📜 .editorconfig     # Padronização de formatação do editor
 ┣ 📜 .gitattributes    # Tratamento de line-endings LF/CRLF
 ┣ 📜 .gitignore        # Arquivos ignorados pelo Git
 ┣ 📜 LICENSE           # Licença MIT
 ┗ 📜 README.md         # Esta documentação
```

## ⚙️ Como rodar localmente
Este é um site 100% estático. Não requer build ou instalação de pacotes complexos.
1. Clone este repositório:
   ```bash
   git clone https://github.com/tgojlima/portfolio.git
   ```
2. Acesse a pasta:
   ```bash
   cd portfolio
   ```
3. Abra o arquivo `index.html` em seu navegador favorito ou utilize uma extensão como o **Live Server** no VS Code.
